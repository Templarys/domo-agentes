# domo-agentes

Agentes de Domo Político Consultores. **Repositorio privado. No contiene datos de clientes ni datos personales.**

- `CLAUDE.md` — reglas de la Secretaria (coordinadora).
- `.claude/agents/` — un archivo por agente, con sus herramientas mínimas.
- `kit/` — marca (logos, Nexa, El Estratega), plantilla del calendario, briefs y plantillas de video.
- `programadas/` — instrucciones de los agentes que corren solos.
- `docs/` — horarios y pendientes.

Plantillas de video: copia la plantilla, las fuentes y las imágenes a una carpeta de trabajo y ejecuta `PAGE=archivo.html H=1920 node render.js <segundos>`.
